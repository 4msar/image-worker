Fetch photos from {{PROVIDER_NAMES}} and get them back as an image, JSON, a redirect, or a browser view. No API key needed on your side.

Usage

Every provider has the same routes. Replace {provider} with a provider id from the list below, or get the list as JSON from /providers.

Route Description
/{provider}/random A random image.
/{provider}/search Search results as JSON, in the same shape for every provider.
/{provider}/photos/:id A single image by its provider id.
/providers The available providers as JSON.

Query parameters

Name Description
query Search term. q works too.
orientation landscape, portrait or squarish.
page1 Results page, for /search.
per_page10 Results per page, for /search. Each provider caps it at its own limit.
# Random landscape photo, small size, as JSON /{{EXAMPLE}}/random?query=nature&orientation=landscape&size=small&type=json # Drop it straight into an <img> tag <img src="/{{EXAMPLE}}/random?query=mountains" />

Providers

Response options

These parameters work on /random and /photos/:id.

Format: type

Value Description
imagedefault Returns the image file itself.
json Returns the response as JSON.
view Opens the image page on the provider’s site.
redirect Redirects to the image URL.

Size: size

Value Description
regulardefault Regular size image.
raw Original, unprocessed image.
full Full size image.
small Small size image.
thumb Thumbnail size image.
